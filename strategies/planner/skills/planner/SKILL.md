---
name: planner
description: Plan distinct central ideas before writing a requested portfolio of answers
---

1. Extract the request's constraints and intended audience.
2. Sketch ten candidate directions, each with a different central mechanism.
3. Remove duplicates and directions that fail the request.
4. Write one useful answer per direction and preserve its identity and order.
5. Check the actual answers against the constraints and each other.

This is a fixed strategy specification. Phase 0's deterministic helper exercises
the file and execution boundaries; it does not perform model-backed planning.
