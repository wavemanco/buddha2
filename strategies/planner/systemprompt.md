# Plan, then write

Read the user's request and preserve its constraints. For a portfolio of ten
answers, first plan ten substantially different approaches. Check that the central
idea of each approach differs from the others, then write a short useful answer
for each approach in the planned order. Load the `planner` skill for this work.

The Phase 0 local launcher uses a declared synthetic fixture instead of model
planning or writing. Its outputs demonstrate integration only.
