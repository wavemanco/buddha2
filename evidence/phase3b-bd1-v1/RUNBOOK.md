# P3B-BD1 unit-preflight runbook

Status: unit evidence complete; independent closure/publication review governs the final outcome. No release or paid campaign is authorized.

The supported operator is `evidence/phase3b-bd1-v1/run_units.py`. Run from the research checkout with its `src`, `.upstream/harness2` and root on `PYTHONPATH`, and bytecode writing disabled. No provider keys are needed or accepted by this workflow.

## Guarded command and preparation

1. Bind the applicable direct instruction, unchanged definition, fresh source manifest and exact case inventory. `freeze MODE NUMBER` creates an absent-before-use invocation root and source/context-bound manifest.
2. An independent reviewer checks the actual command, source, authority, fresh output, runtime resources and case list, then writes the manifest-bound `prospective-review.json` beside it.
3. `python -B evidence/phase3b-bd1-v1/run_units.py run MODE NUMBER` is the unit-only execution command. It authenticates source/review, records admission before work, owns the H1 container, verifies actual containment, runs the selected unit mode and proves exact-owner cleanup. Windows mode uses the actual host with a clean environment instead of H1.

Modes are `bootstrap` (the original first-four-test prefix), `suite` (production `verify.run_tests` discovery/run), and `windows` (the three declared host cases). Profiling is declared only at freeze with `--profile-imports`; its output is typed module/timing events with no raw profile stream retained. It alters startup timing and is not causal proof.

Do not repeat a consumed root, copy a passing receipt to another source, add skips, change assertions/clocks/frozen controls, or interpret development unit bindings as a native study/release gate. These reference commands do not reopen a closed block or authorize another run.
