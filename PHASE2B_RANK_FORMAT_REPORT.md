## What this block tests

Apply one deterministic, score-blind policy, **rank-format-N1**, to all 24 saved rank responses. Compare the original independent-generation baseline A, the original fixed planner/generator B and **C-N**, the original ranking inference followed by N1. There is no new answer, plan or rank generation and no recursive adaptation in this block.

N1 accepts an order only when every complete strict JSON object contains exactly the same permutation of the ten exact parent IDs. It permits surrounding prose/fences and repeated identical objects, but rejects conflicting orders, malformed candidates, extra or duplicate keys, invalid IDs and outside structural delimiters. Limits are 65,536 strict UTF-8 bytes, structural depth two and 16 candidate objects. It makes no typo correction, ID normalization, semantic prose interpretation or score-informed choice.
